Important:
- The PDFs are fillable AcroForm PDFs.
- Users should download or save a copy after filling.
- Browser PDF viewers may vary. For the most reliable filling/saving, use Adobe Acrobat Reader, Microsoft Edge, or Chrome.
- For the PWA, treat these PDFs as printable/fillable templates first. Later, the same fields can be built directly into the app database.

Suggested PWA metadata:
- Store this forms metadata in src/data/forms.ts or src/data/forms.json.
- Use the stage field to show the right forms on each stage screen.
